## Описание
**Обновление исправила некоторые положения в ID, но всё ещё доспускаються ошибки или варны в GameConsole при открытии панели - это не критично!

**MapPanel** —  это компонент административной панели для управления игровыми зонами, дверями и лифтами в рамках системы DeltaEx. Позволяет администраторам быстро находить локации, управлять доступом и состоянием объектов через удобный интерфейс.

1. **Скачайте прикрепленный .dll** и положите его в `Plugins`
2. Назначте нужным ролям требуемое право: `map`
3. Перезапустите сервер.
